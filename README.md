# [강원개발공사 전용] 공공임대주택 사업성 분석

지방공사가 공공임대주택 사업의 총사업비, 재원 조달 구조, 수익성(연도별 운영수지, NPV·IRR·회수기간, 분양전환·매각, 민감도)을 한 사업 단위로 분석하는 업무 도구입니다. 임대료·건축비·재원 요건은 공공주택 특별법령, 국토교통부 고시·훈령, 주택도시기금법, 지방공기업법, 지방재정법 원문 기준입니다(2026.11.20 현행).

## 구성

| 파일 | 역할 |
|---|---|
| `index.html`, `app.js` | 화면 |
| `engine.js` | 계산 엔진 (총사업비, 임대료, 재원, 현금흐름, NPV·IRR, 민감도) |
| `api/rent.js` | 국토교통부 전월세 실거래가 API 중계 (아파트·연립다세대·오피스텔) |
| `api/projects.js` | 사업 저장·목록·삭제 (Vercel Blob 비공개 저장소, 없으면 Upstash Redis) |
| `api/umd.js` | 시군구의 법정동(읍면동) 목록 (실거래 자료 기준) |
| `api/health.js` | 연결 상태 확인 |

## Vercel 배포 순서

1. Vercel에서 **Add New → Project → 이 GitHub 저장소 Import**. Framework Preset은 **Other**, 빌드 설정은 비워 둡니다.
2. **Settings → Environment Variables**에 아래 값을 넣습니다.
   - `DATA_GO_KR_KEY` — 공공데이터포털 일반 인증키(**Decoding** 키). 아래 API를 활용신청한 계정의 키.
     - 국토교통부_아파트 전월세 실거래가 자료
     - 국토교통부_연립다세대 전월세 실거래가 자료
     - 국토교통부_오피스텔 전월세 실거래가 자료
   - `APP_PASSCODE` — 직원끼리 공유할 접근코드(선택). 비워 두면 누구나 실거래가 조회·사업 저장을 쓸 수 있습니다.
3. **Storage → Create → Blob** 에서 접근 방식 **Private** 로 저장소를 만들어 이 프로젝트에 연결합니다. `BLOB_READ_WRITE_TOKEN` 환경변수가 자동으로 들어갑니다. 사업은 `projects/<id>.json` 파일로 저장됩니다.
4. **Deployments → Redeploy** 로 환경변수를 반영합니다.
5. 사이트 상단에 "실거래가 API 연결됨 · 사업 저장소 연결됨"이 보이면 끝입니다.

저장소를 연결하지 않아도 계산은 되고, 저장은 각자 브라우저에 됩니다.

## 계산 가정 (단순화)

- 공사비는 공사기간에 균등 지출, 임대보증금은 준공 연도에 받고 이후 증액분만 추가 수령
- 기금 융자는 거치 후 원금 균등상환, 사채는 차환하며 이자만 내다 분석 종료 시 상환
- 국고·지방비·기금 출자는 상환 의무 없는 외부 재원(공사 관점 현금흐름에서 제외)
- 특별수선충당금은 표준건축비의 1만분의 4를 사용검사 1년 후부터 매달 적립(시행령 제57조⑤)
- 법인세 미반영
